# 持久化结构化流式聊天接口文档

## 接口信息

- **接口名称**: 持久化结构化流式聊天
- **接口路径**: `/api/v1/chat/structured/stream/persistent`
- **请求方法**: `POST`
- **Content-Type**: `application/json`
- **响应类型**: `text/event-stream` (SSE 流式响应)
- **接口描述**: 带会话记忆和数据库存储的流式对话接口。支持多轮对话，自动保存聊天记录到数据库，每个 ChatResponse 对象都会被序列化为一条 `data: {...}` 的消息

## 核心特性

1. **流式输出**: 使用 SSE (Server-Sent Events) 技术，实时推送 AI回复内容
2. **持久化存储**: 自动将会话和消息保存到数据库
3. **上下文记忆**: 基于 sessionId 实现多轮对话上下文记忆
4. **结构化响应**: 每个响应块包含完整的结构化信息（内容、模型、token 使用等）

## 请求参数

### 请求头

| 参数名 | 类型 | 必填 | 说明                                     | 示例                 |
|--------|------|------|----------------------------------------|--------------------|
| Content-Type | String | 是 | 固定为 `application/json`                 | `application/json` |
| X-User-Id | String | 否 | 用户 ID（优先级高于请求体中的 userId），从localstore取值 | `UUID`             |

### 请求体参数

**数据结构**: `ChatRequest`

| 字段名 | 类型 | 必填 | 默认值 | 说明 | 示例                     |
|--------|------|------|--------|------|------------------------|
| message | String | 是 | - | 用户消息内容 | `你好，介绍一下你自己`           |
| sessionId | String | 否 | 自动生成 | 会话 ID，用于关联历史对话 | `UUID`                 |
| userId | String | 否 | - | 用户 ID（可被请求头覆盖） | `UUID`                 |
| model | String | 否 | `deepseek-r1:8b` | 使用的 AI 模型名称 | `deepseek-r1:8b`       |
| stream | Boolean | 是 | `false` | 是否启用流式输出（必须为 true） | `true`                 |
| systemMessage | String | 否 | - | 系统提示词/角色设定 | `你是一个专业、清晰、可靠的 AI 助手，默认使用中文回答。` |
| temperature | Double | 否 | `0.7` | 温度参数 (0-2)，控制随机性 | `0.7`                  |
| maxTokens | Integer | 否 | `2048` | 最大生成 token 数 | `2048`                 |
| tools | List<Tool> | 否 | - | 工具列表（函数调用） | 见下方示例                  |

## 响应信息

### 成功响应

**响应状态码**: `200 OK`

**响应格式**: `text/event-stream`

**SSE 消息格式**:
```
data: {"content":"你","model":"deepseek-r1:8b","timestamp":1234567890,"success":true}
data: {"content":"好","model":"deepseek-r1:8b","timestamp":1234567891,"success":true}
data: {"content":"！","model":"deepseek-r1:8b","timestamp":1234567892,"success":true,"tokenUsage":{"promptTokens":10,"completionTokens":5,"totalTokens":15}}
```

### ChatResponse 数据结构（每个数据块）

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| content | String | AI回复的内容片段（流式累积） | `你好` |
| model | String | 使用的模型名称 | `deepseek-r1:8b` |
| timestamp | Long | 响应时间戳（毫秒） | `1708595430000` |
| success | Boolean | 是否成功 | `true` |
| errorMessage | String | 错误信息（如有） | `null` |
| tokenUsage | TokenUsage | Token 使用情况（通常在最后一个块中） | 见下方 |

### TokenUsage 数据结构

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| promptTokens | Integer | 提示词消耗的 token 数 | `10` |
| completionTokens | Integer | 生成内容消耗的 token 数 | `50` |
| totalTokens | Integer | 总消耗的 token 数 | `60` |

```javascript
// 基础用法
function startChat() {
  const requestPayload = {
    message: "你好，介绍一下你自己",
    model: "deepseek-r1:8b",
    stream: true,
    temperature: 0.7,
    maxTokens: 2048
  };

  fetch('http://localhost:8080/api/v1/chat/structured/stream/persistent', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-User-Id': 'user_789012'
    },
    body: JSON.stringify(requestPayload)
  })
  .then(response => {
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    
    function read() {
      return reader.read().then(({ done, value }) => {
        if (done) {
          console.log('流式传输完成');
          return;
        }
        
        const chunk = decoder.decode(value);
        // 解析 SSE 消息
        const lines = chunk.split('\n');
        lines.forEach(line => {
          if (line.startsWith('data: ')) {
            const data = JSON.parse(line.slice(6));
            console.log('收到消息块:', data.content);
            
            // 累积显示完整回复
            appendToDisplay(data.content);
            
            // 检查是否有 token 使用信息
            if (data.tokenUsage) {
              console.log('Token 使用统计:', data.tokenUsage);
            }
          }
        });
        
        return read();
      });
    }
    
    return read();
  })
  .catch(error => {
    console.error('流式聊天失败:', error);
  });
}

// 多轮对话示例
async function multiTurnConversation() {
  let sessionId = null;
  
  // 第一轮对话
  const response1 = await sendChatMessage("我想学习 Python", null);
  sessionId = response1.sessionId; // 从响应中获取 sessionId
  
  // 第二轮对话（使用相同的 sessionId）
  const response2 = await sendChatMessage("如何练习？", sessionId);
}

function sendChatMessage(message, sessionId) {
  return new Promise((resolve, reject) => {
    const payload = {
      message: message,
      sessionId: sessionId,
      model: "deepseek-r1:8b",
      stream: true
    };
    
    let fullContent = '';
    let returnedSessionId = sessionId;
    
    fetch('http://localhost:8080/api/v1/chat/structured/stream/persistent', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-User-Id': 'user_789012'
      },
      body: JSON.stringify(payload)
    })
    .then(response => {
      const reader = response.body.getReader();
      const decoder = new TextDecoder();
      
      function read() {
        return reader.read().then(({ done, value }) => {
          if (done) {
            resolve({ 
              content: fullContent,
              sessionId: returnedSessionId
            });
            return;
          }
          
          const chunk = decoder.decode(value);
          const lines = chunk.split('\n');
          lines.forEach(line => {
            if (line.startsWith('data: ')) {
              const data = JSON.parse(line.slice(6));
              fullContent += data.content;
              if (data.sessionId) {
                returnedSessionId = data.sessionId;
              }
            }
          });
          
          return read();
        });
      }
      
      return read();
    })
    .catch(reject);
  });
}
```

### Python (requests + SSE)

```python
import requests
import json

def stream_chat():
    """流式聊天示例"""
    url = "http://localhost:8080/api/v1/chat/structured/stream/persistent"
    
    payload = {
        "message": "你好，介绍一下你自己",
        "model": "deepseek-r1:8b",
        "stream": True,
        "temperature": 0.7,
        "maxTokens": 2048
    }
    
    headers = {
        "Content-Type": "application/json",
        "X-User-Id": "user_789012"
    }
    
    response = requests.post(url, headers=headers, json=payload, stream=True)
    
    full_content = ""
    
    for line in response.iter_lines():
        if line:
            line = line.decode('utf-8')
            if line.startswith('data: '):
                data = json.loads(line[6:])
                
                if data.get('content'):
                    print(data['content'], end='', flush=True)
                    full_content += data['content']
                
                if data.get('tokenUsage'):
                    print(f"\n\nToken 使用统计:")
                    print(f"  Prompt Tokens: {data['tokenUsage']['promptTokens']}")
                    print(f"  Completion Tokens: {data['tokenUsage']['completionTokens']}")
                    print(f"  Total Tokens: {data['tokenUsage']['totalTokens']}")
    
    print(f"\n\n完整回复：{full_content}")

def multi_turn_conversation():
    """多轮对话示例"""
    session_id = None
    
    # 第一轮
    session_id = send_message("我想学习 Python 编程", session_id)
    
    # 第二轮

    # 第三轮

def send_message(message, session_id=None):
    """发送单条消息"""
    url = "http://localhost:8080/api/v1/chat/structured/stream/persistent"
    
    payload = {
        "message": message,
        "sessionId": session_id,
        "model": "deepseek-r1:8b",
        "stream": True
    }
    
    headers = {
        "Content-Type": "application/json",
        "X-User-Id": "user_789012"
    }
    
    response = requests.post(url, headers=headers, json=payload, stream=True)
    
    full_content = ""
    returned_session_id = session_id
    
    for line in response.iter_lines():
        if line:
            line = line.decode('utf-8')
            if line.startswith('data: '):
                data = json.loads(line[6:])
                
                if data.get('content'):
                    full_content += data['content']
                
                if data.get('sessionId'):
                    returned_session_id = data['sessionId']
```

```vue
      if (!this.userInput.trim() || this.isStreaming) return

        content: message
      })

      this.currentStreamingContent = ''

        const response = await fetch(

          {
            method: 'POST',
            headers: {
              'Content-Type': 'application/json',
              'X-User-Id': this.userId
            },
            body: JSON.stringify({
              message: message,
              sessionId: this.sessionId,
              model: 'deepseek-r1:8b',
              stream: true,
              temperature: 0.7,
              maxTokens: 2048
            })
          }
        )
        
        const reader = response.body.getReader()
        const decoder = new TextDecoder()
        
        while (true) {
          const { done, value } = await reader.read()
          if (done) break
          
          const chunk = decoder.decode(value)
          const lines = chunk.split('\n')
          
          for (const line of lines) {
            if (line.startsWith('data: ')) {
              const data = JSON.parse(line.slice(6))
              
              if (data.content) {
                this.currentStreamingContent += data.content
              }
              
              if (data.sessionId && !this.sessionId) {
                this.sessionId = data.sessionId
              }
              
              if (data.tokenUsage) {
                console.log('Token 使用:', data.tokenUsage)
              }
            }
          }
        }
        
        // 将 AI回复添加到消息列表
        this.messages.push({
          role: 'assistant',
          content: this.currentStreamingContent
        })
        
        this.currentStreamingContent = ''
        
      } catch (error) {
        console.error('聊天失败:', error)
        this.messages.push({
          role: 'system',
          content: '发生错误，请稍后重试'
        })

        this.isStreaming = false
      }
    }
  }
```

## 错误处理

```json
data: {"content":null,"model":null,"timestamp":1708595430000,"success":false,"errorMessage":"消息内容不能为空"}
```

**错误 2: 会话不存在**

## 注意事项

1. **流式输出**: 响应类型为 `text/event-stream`，客户端需要支持 SSE 协议
2. **sessionId 管理**: 
   - 首次对话可不传 sessionId，系统会自动生成
   - 后续对话应使用返回的 sessionId 以保持上下文
3. **userId 优先级**: 请求头 `X-User-Id` > 请求体 `userId` 字段
4. **Token 统计**: `tokenUsage` 通常在最后一个响应块中返回
5. **连接保持**: SSE 连接会保持打开直到响应完成，注意超时设置
6. **并发限制**: 同一用户同时发起多个流式请求可能导致性能问题
7. **数据持久化**: 所有对话都会保存到数据库，注意隐私和数据安全

```javascript
  },
  
  getSession() {
    return this.currentSessionId || localStorage.getItem('currentSessionId');
  },
  
  clearSession() {
    this.currentSessionId = null;
    localStorage.removeItem('currentSessionId');
  }
};
```

### 2. 重连机制
```javascript
async function chatWithRetry(message, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await sendChatMessage(message);
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      console.log(`重试 ${i + 1}/${maxRetries}`);
      await new Promise(resolve => setTimeout(resolve, 1000 * (i + 1)));
    }
  }
}
```
