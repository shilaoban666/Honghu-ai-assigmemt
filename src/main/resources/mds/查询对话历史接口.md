# 查询对话历史接口文档

## 接口信息

- **接口名称**: 查询对话历史
- **接口路径**: `/api/v1/chat/history/{sessionId}`
- **请求方法**: `GET`
- **接口描述**: 根据会话 ID 查询该会话的所有历史聊天消息，按创建时间升序排列

## 请求参数

### 路径参数

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| sessionId | String | 是 | 会话 ID，用于唯一标识一个聊天会话 | `session_123456` |

### 请求头

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Content-Type | String | 否 | 固定为 `application/json` |

### 请求体

无

## 响应信息

### 成功响应

**响应状态码**: `200 OK`

**响应格式**: `application/json`

**响应数据结构**: `List<ChatMessage>`

### ChatMessage 数据结构

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| chatId | Long | 消息 ID（主键） | `1001` |
| sessionId | String | 会话 ID | `session_123456` |
| chatRole | String | 消息角色（system/user/assistant） | `user` |
| contentType | String | 内容类型 | `text` |
| status | String | 消息状态（pending/completed 等） | `completed` |
| content | String | 消息内容 | `你好，请帮我解答这个问题` |
| createdAt | LocalDateTime | 消息创建时间 | `2026-02-22T10:30:00` |

## 错误响应

| 状态码 | 说明 | 响应示例 |
|--------|------|----------|
| 404 Not Found | 会话不存在或没有该会话的消息 | `[]` (返回空数组) |
| 500 Internal Server Error | 服务器内部错误 | 根据全局异常处理器返回相应错误信息 |

## 使用示例

### cURL 示例

```bash
curl -X GET "http://localhost:8080/api/v1/chat/history/session_123456" \
  -H "Content-Type: application/json"
```

### JavaScript (Fetch) 示例

```javascript
fetch('http://localhost:8080/api/v1/chat/history/session_123456', {
  method: 'GET',
  headers: {
    'Content-Type': 'application/json'
  }
})
.then(response => response.json())
.then(data => {
  console.log('对话历史:', data);
  // 处理返回的对话历史数据
  data.forEach(message => {
    console.log(`${message.chatRole}: ${message.content}`);
  });
})
.catch(error => {
  console.error('获取对话历史失败:', error);
});
```

### Java (RestTemplate) 示例

```java
RestTemplate restTemplate = new RestTemplate();
String url = "http://localhost:8080/api/v1/chat/history/{sessionId}";

List<ChatMessage> history = restTemplate.getForObject(
    url, 
    List.class,  // 实际使用时应替换为 ChatMessage 的 List 类型
    "session_123456"
);

// 遍历历史消息
for (ChatMessage message : history) {
    System.out.println(message.getChatRole() + ": " + message.getContent());
}
```

### Python (requests) 示例

```python
import requests

url = "http://localhost:8080/api/v1/chat/history/session_123456"
response = requests.get(url)

if response.status_code == 200:
    messages = response.json()
    for message in messages:
        print(f"{message['chatRole']}: {message['content']}")
else:
    print(f"请求失败，状态码：{response.status_code}")
```

## 注意事项

1. **排序规则**: 返回的消息列表按照 `createdAt` 字段**升序**排列（从旧到新），便于查看完整的对话流程
2. **空结果**: 如果指定会话不存在或没有任何消息，将返回空数组 `[]`
3. **会话 ID**: 会话 ID 通常由系统在创建会话时生成，可通过会话管理接口获取
4. **性能考虑**: 对于消息数量较多的会话，建议在前端实现分页或虚拟滚动以优化性能
