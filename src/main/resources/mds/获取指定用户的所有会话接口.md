# 获取指定用户的所有会话接口文档

## 接口信息

- **接口名称**: 获取指定用户的所有会话
- **接口路径**: `/api/v1/sessions/user/{userId}`
- **请求方法**: `GET`
- **接口描述**: 根据用户 ID 获取该用户下的所有聊天会话列表，按创建时间倒序排列（最新的会话排在最前面）

## 请求参数

### 路径参数

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| userId | String | 是 | 用户 ID，用于唯一标识一个用户 | `user_789012` |

### 请求头

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Content-Type | String | 否 | 固定为 `application/json` |

### 请求体

无

## 响应信息

### 成功响应

**响应状态码**: `200 OK`

**响应格式**: `application/json`

**响应数据结构**: `List<ChatSession>`

### ChatSession 数据结构

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| sessionId | String | 会话 ID（主键） | `session_123456` |
| userId | String | 用户 ID | `user_789012` |
| userName | String | 用户名称 | `张三` |
| systemRole | String | 系统角色设定 | `AI 助手` |
| sessionName | String | 会话名称 | `关于 Spring AI 的讨论` |
| sessionStatus | String | 会话状态（active/archived 等） | `active` |
| title | String | 会话标题 | `Spring AI 学习` |
| createdAt | LocalDateTime | 会话创建时间 | `2026-02-22T10:30:00` |

## 错误响应

| 状态码 | 说明 | 响应示例 |
|--------|------|----------|
| 404 Not Found | 用户不存在或没有会话 | `[]` (返回空数组) |
| 500 Internal Server Error | 服务器内部错误 | 根据全局异常处理器返回相应错误信息 |

## 使用示例

### cURL 示例

```bash
curl -X GET "http://localhost:8080/api/v1/sessions/user/user_789012" \
  -H "Content-Type: application/json"
```

### JavaScript (Fetch) 示例

```javascript
fetch('http://localhost:8080/api/v1/sessions/user/user_789012', {
  method: 'GET',
  headers: {
    'Content-Type': 'application/json'
  }
})
.then(response => response.json())
.then(data => {
  console.log('会话列表:', data);
  // 处理返回的会话数据
  data.forEach(session => {
    console.log(`[${session.sessionId}] ${session.sessionName} - ${session.createdAt}`);
  });
  
  // 可以选择某个会话查看详情
  const selectedSession = data[0];
  console.log('选中的会话:', selectedSession.sessionName);
})
.catch(error => {
  console.error('获取会话列表失败:', error);
});
```

### Java (RestTemplate) 示例

```java
RestTemplate restTemplate = new RestTemplate();
String url = "http://localhost:8080/api/v1/sessions/user/{userId}";

List<ChatSession> sessions = restTemplate.getForObject(
    url, 
    List.class,  // 实际使用时应替换为 ChatSession 的 List 类型
    "user_789012"
);

// 遍历会话列表
for (ChatSession session : sessions) {
    System.out.println(String.format(
        "会话 ID: %s, 名称：%s, 创建时间：%s",
        session.getSessionId(),
        session.getSessionName(),
        session.getCreatedAt()
    ));
}

// 获取最新的会话（第一个）
if (!sessions.isEmpty()) {
    ChatSession latestSession = sessions.get(0);
    System.out.println("最新会话：" + latestSession.getSessionName());
}
```

### Python (requests) 示例

```python
import requests

url = "http://localhost:8080/api/v1/sessions/user/user_789012"
response = requests.get(url)

if response.status_code == 200:
    sessions = response.json()
    print(f"共有 {len(sessions)} 个会话:")
    for session in sessions:
        print(f"[{session['sessionId']}] {session['sessionName']} - {session['createdAt']}")
    
    # 获取最新会话
    if sessions:
        latest = sessions[0]
        print(f"\n最新会话：{latest['sessionName']}")
else:
    print(f"请求失败，状态码：{response.status_code}")
```

## 注意事项

1. **排序规则**: 返回的会话列表按照 `createdAt` 字段**倒序**排列（最新的会话排在最前面），方便用户快速找到最近使用的会话
2. **空结果**: 如果用户不存在或没有任何会话，将返回空数组 `[]`
3. **用户 ID**: 用户 ID 通常由用户认证系统提供，确保唯一性
4. **会话数量**: 如果一个用户有大量会话，建议实现分页查询功能
5. **会话状态**: 注意检查 `sessionStatus` 字段，可能需要过滤已归档或删除的会话

## 典型使用场景

### 场景 1: 用户登录后加载会话列表

```javascript
// 用户登录后
async function loadUserSessions(userId) {
  try {
    const response = await fetch(`/api/v1/sessions/user/${userId}`);
    const sessions = await response.json();
    
    // 渲染会话列表到 UI
    renderSessionList(sessions);
    
    // 自动选中最新会话
    if (sessions.length > 0) {
      selectSession(sessions[0].sessionId);
    }
  } catch (error) {
    console.error('加载会话列表失败:', error);
  }
}
```

### 场景 2: 查看特定会话的历史记录

```javascript
// 先获取会话列表
const sessions = await fetch('/api/v1/sessions/user/user_789012')
  .then(res => res.json());

// 选择某个会话
const selectedSession = sessions.find(s => s.sessionId === 'session_123456');

if (selectedSession) {
  // 查询该会话的历史消息
  const history = await fetch(`/api/v1/chat/history/${selectedSession.sessionId}`)
    .then(res => res.json());
  
  // 显示历史消息
  displayMessages(history);
}
```
